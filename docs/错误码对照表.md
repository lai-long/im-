# 错误码对照表

> 版本：v0.4（对应 M1a / M1b / M2）
> 维护约定：每实现一个错误码即登记，逐条标注**官方出处**（文档 path）与触发条件；
> 官方未公布的错误码，标注为「平台自定义」，并在下表中说明取值理由。
> 协议基线见 [设计文档](./设计文档.md) §7.4。

## 1. webhook/send（群机器人发送）

| errcode | errmsg | 触发条件 | 官方出处 | 备注 |
|---|---|---|---|---|
| 0 | ok | 发送成功 | 群机器人 webhook（`path/91770`） | — |
| 93000 | invalid webhook key | `key` 缺失或无效；机器人已不在该群 | 群机器人 webhook（`path/91770`） | 本地不产生「被移出群」，仍保留该码 |
| 93001 | 机器人已被移出群 | 预留 | 同 93000 所在文档 | M1a 未触发路径 |
| 40058 | invalid msgtype | msgtype 非 `text`/`markdown`/`markdown_v2`/`image`/`news`/`template_card`/`file`/`voice`（M2 全量支持） | 企微通用错误码（应用消息 `path/90236`） | 群机器人专用码待核对 |
| 40004 | invalid media type | webhook/upload_media 的 `type` 非 `file`/`voice` | 企微通用错误码 | — |
| 40005 | invalid media file | 素材解析失败 / `media` 字段缺失 / 文件为空 | 企微通用错误码 | — |
| 40008 | invalid content, text empty | text/markdown 的 `content` 缺失或为空 | 企微通用错误码 | 待核对 |
| 45002 | content size out of range | text > 2048 字节 / markdown > 4096 字节 | 应用消息长度限制（`path/90236`） | 群机器人限制同值 |
| 40035 | invalid json | 请求体 JSON 解析失败 | 企微通用错误码 | 待核对 |
| 500 | internal error | 平台内部错误（落库失败等） | **平台自定义** | 官方无对应码；本地排障优先看控制台消息流水 |

## 2. aibot/response（response_url 主动回复）

官方文档（`path/101138`）未公布该路径的错误码，平台统一用 `40001` 表示
「response_code 无效」，以 `errmsg` 区分具体原因：

| errcode | errmsg | 触发条件 | 官方出处 |
|---|---|---|---|
| 0 | ok | 回复成功落群 | — |
| 40001 | response_code store: not found | `response_code` 不存在 | **平台自定义** |
| 40001 | response_code already used | 已使用（一次性语义） | **平台自定义**（语义见 `path/101138`） |
| 40001 | response_code expired | 超过 1 小时有效期 | **平台自定义**（1 小时见 `path/101138`） |
| 40001 | response_code 缺失 | 查询参数缺失 | **平台自定义** |
| 40001 | response_code 已使用或已过期 | 并发占用失败 | **平台自定义** |
| 40058 | invalid msgtype | 非 `markdown`（M1a）；`template_card` 待 M1b | 企微通用错误码 |
| 40008 | invalid content, markdown empty | markdown 内容为空 | 企微通用错误码 |
| 45002 | content size out of range | markdown > 4096 字节 | 应用消息长度限制 |

## 4. 通讯录只读接口 user/get、user/simplelist（M2）

只读通讯录，复用自建应用的 token 校验（`requireToken`）：

| errcode | errmsg | 触发条件 | 官方出处 |
|---|---|---|---|
| 0 | ok | 查询成功 | 通讯录管理（`path/90195`） |
| 41001 | access_token missing | 未带 access_token | 企微全局错误码表（见 §3） |
| 40014 | invalid access_token | token 无效/不存在 | 企微全局错误码表（见 §3） |
| 60111 | userid missing | `user/get` 缺 `userid` 参数 | 通讯录错误码（`path/90195`，60111=userid 不存在） |
| 60111 | userid not found | `user/get` 的 userid 在平台不存在 | 同上（本地无"部门/标签"维度，统一归 60111） |

`user/simplelist` 仅要求合法 token，返回全量用户 `{userid,name}`；不单独定义错误码。

## 5. webhook/upload_media（群机器人素材，M2）

`POST /cgi-bin/webhook/upload_media?key=xxx&type=file|voice`，与自建应用 `media/upload` 不同（机器人走 webhook key 鉴权）：

| errcode | errmsg | 触发条件 | 官方出处 |
|---|---|---|---|
| 0 | ok | 上传成功，返回 `media_id` | 群机器人素材（`path/91770`） |
| 93000 | invalid webhook key | `key` 缺失或无效 | 同 §1（webhook key 鉴权） |
| 40004 | invalid media type | `type` 非 `file`/`voice` | 企微通用错误码 |
| 40005 | invalid media file | 表单解析失败 / `media` 字段缺失 / 文件为空 | 企微通用错误码 |

素材下载（自建应用侧 `GET /cgi-bin/media/get`）复用 §3 的 token 校验，无独立错误码。
